The gatekeeper rule

"Never trust the client." Every write passes two layers before it touches data:

  1. Syntactic — types, lengths, enums, formats. {"name": "x"} dies here.
  2. Semantic — domain rules, e.g. project names must be unique. Duplicates die here.

Violations return HTTP 400 with the failing layer named per field. Hammer an endpoint and the sliding-window limiter answers HTTP 429 with a Retry-After header.
